# Changelog

## 0.1.0 (unreleased)

First public preview of the core loop: canvas requests → Generate → Keep/Undo → visual edits → save/reopen → export a website folder. Release remains subject to the [preview blockers](RELEASE_PLAN.md#preview-blockers).

- Create blank projects, draw and describe requests on the canvas, and choose Flexible or Precise AI style.
- Generate using your own API key or an authorized ChatGPT plan, review changes on the canvas, keep them or undo them, and follow progress in the AI log.
- Edit text, styles, positions and sizes visually; target AI changes to selected elements or pages. Merge generation results with compatible edits made while generation runs.
- Work across pages and open projects, import existing websites or brand context, and inspect sites in Live view or a browser.
- Save and reopen editable projects with recovery and backups; export standalone website folders with styles, scripts and portable assets.
- Keep large imported sites responsive with lazy preview rendering and recovery storage that keeps site files outside the edit journal. Group bursts of edits into one history step.
- Explain unwritable app-data folders and missing desktop portals. Offer opt-in, scrubbed crash reports through prefilled GitHub issues.
- Check GitHub Releases manually for updates and open the release download page; no automatic installation.
- Add private security-reporting instructions, an install and first-site guide, and a release-notes template naming the exact GPL-3.0-only source and checksums.

Linux is the tested platform. Windows/macOS builds are untested previews; signing, notarization, the signed updater and remaining 1.0 features are deferred.
