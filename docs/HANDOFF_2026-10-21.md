## Suggested Codex work (backend-heavy, in priority order)

1. **Keep pictures as references inside saved pages.**
   - Today a placed picture is stored as Base64 in the page HTML. It is copied into every undo step (200) and every recovery snapshot.
   - Store `desegnos-asset:<id>` in page source instead, and resolve only for preview and export. Include a migration that pulls existing inline images into a project picture store.
   - Biggest memory and speed win for photo-heavy sites.
2. **Drop the duplicated result schema from the requirements text.** The schema (~8 KB) is written into REQUIREMENTS.md and also sent as the structured-output schema. Add format 12 without the written copy, which saves ~2k tokens per generation. Older formats must stay byte-identical.
3. **Record the element-fix follow-up.**
   - Save the second request (the `needs` round) as `CONTEXT.md` in the job folder.
   - Expose it in `GenerationJobView`, so the AI conversation sidebar can show both rounds.
4. **Keep raw replies for failed generations,** bounded and with credentials scrubbed. Then "did not match the format" errors can be diagnosed afterwards. (Today only parsed results are stored.)
5. **Past generations list.** A command that lists job records for the open project (time, status, tokens, summary), for a "Past generations" section in the AI log.
6. **Website import that follows links.** URL import reads only the home page. Follow same-site links to project, tutorial and blog pages (bounded crawl: same host, ≤20 pages, same safety rules as now), so the existing-work list has real links and summaries.
7. **Import choices.** Let the user untick photos or work items before "Add to project" (`reviewed_context` currently includes all of them). Add WebP photo support (needs the `image` webp feature). Sort the folder walk so the kept photos are deterministic.
8. **Element fixes that need styling rules.** Element requests can't change the shared stylesheet, so the AI uses inline styles. Consider allowing new rules that only target the selected element's own `data-desegnos-id`, validated by the scope check.
9. **Flaky native step.** `cleanup-extras` "Code editing": Ctrl+Z straight after native typing sometimes doesn't undo. Likely needs a wait for the editor transaction to settle.
10. **Optional code rename** of `desegni-*` crates, `desegni_*` paths and `DESEGNI_*` test env vars to `desegnos`. Mechanical; must not touch the storage identifiers listed above.
